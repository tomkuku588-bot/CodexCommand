工作流指挥舱隐私政策

本政策说明工作流指挥舱如何处理用户信息。本应用是面向独立开发者的本地工作流工具，不是官方 Codex 客户端，不接入 AI 服务，不提供聊天、账号或云同步功能。

一、政策展示与同意方式

本应用首次启动时会显著提示用户阅读《隐私政策》和《用户协议》。如果用户不同意，本应用将退出核心功能，不进入首页、项目舱、详情页或归档页。用户同意后，应用会在本地保存协议同意状态，用于避免每次启动重复提示。

用户可在应用内“设置/合规信息”页面再次查看隐私政策、用户协议和权限说明摘要。

二、我们处理的信息

工作流指挥舱坚持必要、明确、最小化原则。本应用不要求用户填写姓名、手机号、身份证号、账号、头像等身份信息；如果用户在项目内容中自行输入包含个人信息的文字，该信息仅作为本地业务内容保存在用户设备中。

三、本地存储与安全

本应用使用 HarmonyOS Preferences 在设备本地保存 JSON 状态，主要包括项目标题、目标、仓库线索、标签、上下文条目、检查点、执行证据、风险条目、归档状态和协议同意状态。

本应用不会把这些内容上传到服务器，不会向第三方共享，不会用于广告投放、用户画像或跨应用追踪。请用户妥善保管设备和系统账号，避免因设备丢失、系统故障、清除应用数据或卸载应用导致本地数据丢失。

四、权限使用说明

当前版本不申请任何敏感权限或特殊权限。工程配置中未声明 requestPermissions，不请求网络、定位、相机、麦克风、通讯录、电话、短信、日历、相册或文件读取等权限。

由于不申请权限，用户不会遇到系统权限授权弹窗；拒绝隐私政策或用户协议时，应用会退出核心功能。

五、第三方 SDK 与数据共享

当前版本不集成第三方 SDK，不接入广告、统计、推送、支付、地图、云存储、AI API 或官方 Codex 服务。本应用不会出售、出租、转让或公开披露用户本地内容。

如后续增加第三方服务，我们会在上线前更新本政策，说明第三方名称、使用目的、共享信息范围、隐私政策链接，并在必要时重新征得用户同意。

六、用户权利

  • 访问与更正：用户可以在应用内查看、编辑项目舱、上下文、检查点、证据和风险内容。
  • 删除：用户可以删除业务内容，或通过系统设置清除应用数据、卸载应用以移除本地保存的数据。
  • 撤回同意：用户可以通过清除应用数据撤回已保存的协议同意状态；再次启动时需要重新阅读并同意。
  • 咨询与投诉：用户可通过联系邮箱提出隐私相关问题，我们会在合理期限内回复。

七、未成年人保护

本应用主要面向具备独立开发能力的成年用户，不以未成年人为主要服务对象。未成年人使用本应用前，应取得监护人同意并在监护人指导下使用。

八、政策更新

如产品功能、数据处理方式或合规要求发生变化，我们会更新本政策，并通过应用内提示、版本说明或应用市场页面提醒用户。重大变化会在用户继续使用相关功能前进行显著提示。

九、联系我们

如对本政策或个人信息保护相关事项有疑问、建议或投诉，请发送邮件至 tomkuku588@gmail.com。

English Version

1. Policy Notice and Consent

When the app is launched for the first time, users will be clearly asked to read the Privacy Policy and the User Agreement. If a user does not agree, the app will exit its core features and will not enter the home page, project deck, detail page or archive page. After consent is given, the app stores the consent status locally to avoid showing the same notice on every launch.

Users can review the Privacy Policy, User Agreement and permission summary again from the in-app Settings/Compliance Information page.

2. Information We Process

Workflow Command Deck follows the principles of necessity, clarity and data minimization. The app does not ask users to provide names, phone numbers, ID numbers, accounts, avatars or other identity information. If a user voluntarily enters personal information into project content, that information is stored only as local business content on the user's device.

3. Local Storage and Security

The app uses HarmonyOS Preferences to store JSON state locally on the device, including project titles, goals, repository clues, tags, context entries, checkpoints, execution evidence, risk items, archive status and consent status.

The app does not upload this content to servers, share it with third parties, use it for advertising, build user profiles or perform cross-app tracking. Users should protect their devices and system accounts to avoid local data loss caused by device loss, system failure, app data clearing or app uninstallation.

4. Permissions

The current version does not request any sensitive or special permissions. The project configuration does not declare requestPermissions and does not request network, location, camera, microphone, contacts, phone, SMS, calendar, photos or file-reading permissions.

Because no system permissions are requested, users will not see system permission dialogs. If a user refuses the Privacy Policy or User Agreement, the app exits its core features.

5. Third-Party SDKs and Sharing

The current version does not integrate third-party SDKs and does not use advertising, analytics, push notifications, payments, maps, cloud storage, AI APIs or official Codex services. The app does not sell, rent, transfer or publicly disclose users' local content.

If third-party services are added in the future, we will update this policy before release, explain the third party's name, purpose, scope of shared information and privacy policy link, and request consent again where required.

6. User Rights

  • Access and correction: users can view and edit project decks, context, checkpoints, evidence and risk content in the app.
  • Deletion: users can delete business content, clear app data through system settings or uninstall the app to remove locally stored data.
  • Withdrawal of consent: users can clear app data to remove the saved consent status. On the next launch, they will need to read and agree again.
  • Questions and complaints: users can contact us by email with privacy-related questions, and we will respond within a reasonable period.

7. Minors

The app is mainly intended for adult users with independent development capabilities and is not primarily directed to minors. Minors should obtain guardian consent and use the app under guardian guidance.

8. Policy Updates

If product features, data processing methods or compliance requirements change, we will update this policy and notify users through in-app notices, release notes or app marketplace pages. Material changes will be prominently shown before users continue using the affected features.

9. Contact Us

For questions, suggestions or complaints about this policy or personal information protection, please email tomkuku588@gmail.com.

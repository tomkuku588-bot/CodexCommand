二、服务内容

工作流指挥舱面向独立开发者提供本地 Codex 工作流配套能力，帮助用户创建项目舱、整理上下文包、拆解检查点、记录执行证据、登记风险并形成复盘归档。

  • 项目舱管理：创建、编辑、查看、完成、归档和恢复本地项目舱。
  • 上下文管理：按需求、约束、决策、文件线索和备注整理本地上下文。
  • 检查点推进：维护待办、进行中、阻塞、已验证和完成状态。
  • 执行证据：记录命令摘要、人工检查、决策和验证结果。
  • 风险复盘：登记风险、缓解方案和完成后的复盘摘要。

2. Service Scope

Workflow Command Deck provides local Codex workflow support for independent developers. It helps users create project decks, organize context packs, break down checkpoints, record execution evidence, register risks and archive retrospectives.

  • Project deck management: create, edit, view, complete, archive and restore local project decks.
  • Context management: organize local context by requirements, constraints, decisions, file clues and notes.
  • Checkpoint progress: maintain todo, in-progress, blocked, verified and completed states.
  • Execution evidence: record command summaries, manual checks, decisions and verification results.
  • Risk retrospectives: register risks, mitigation plans and completion summaries.
